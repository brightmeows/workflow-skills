# AI 味审计（ai-taste）

审计中文文本的表达与句式。审计的是质量信号，不判作者身份；输出命名病征与判定，不给“AI 概率百分比”。结构与信息设计、无效指令（no-op）归 `writing-for-agents`；技术文档的清晰度问题（指代歧义、一句多指令、术语漂移、超长句）归 `tech-doc-zh`。

## 豁免线

列表、编号步骤、加粗术语、对称小标题是提示词文档的正常骨架；破折号、排比、成语、三段式单独出现一律放过。只有高密度扎堆、多模式同现才算病。改写时降密度，不搞零容忍。

探针分词面与结构两层：词面特征随模型世代漂移（超额词会退潮，厂商会按公开探针降频），位置与结构特征抗改写。本清单以密度与结构判据为主、不设词单，是刻意选择。

## 用法

先判文本类型以定豁免与专属格：提示词文档（AGENTS.md、SKILL.md、系统提示词）或散文评论，混合文档两者都查。病征按判定单元分格，从篇章逐格收窄到句内，每格先查通用，再查本文体专属；只有散文标签的格，提示词文档整格跳过；风格组殿后用通读收尾。逐条对照，命中就引原句、执行判据动作；动作不通过的不成立，记入保留意见。审计即止，用户要求改写才动笔。

## 病征

### 篇章

**通用**

1. **对称小标题无实体**——删掉标题重读，内容独立成立吗？撑不起就并进相邻节。

**散文**

1. **结构可预测**——抽每段首句连读，成通顺摘要吗？段段按“是什么→为什么→结果→意义”推进、通篇没有一段比较或翻案吗？是就重排，让问题先于铺垫出现。
2. **分布均匀**——全篇段落长度高度一致，无独句成段也无超长段吗？首中尾三段取样，中段找得到开头预测不到的内容吗？等长就拆并，中段答不出就换内容。
3. **编号枚举撑全文**——正文反复“第一/第二/第三”，节奏像念目录吗？教学体豁免；改写换时间、因果或场景推进，编号用量压到一半。
4. **标题预告结论**——看完标题就知道结论吗？放 PPT 目录页违和吗？标题写处境，不写判断。

### 段内

**散文**

1. **口号化收束与金句铸句**——删掉段尾句，段落还成立吗？“这就是 X 的力量”“X 是 Y 的 Z”还原不出具体主张就删；连续两段收在漂亮总结句即超标。
2. **时代帽开场**——删掉第一段，文章少了什么？答不出就是暖身；真在论时代变迁且续接具体数据的放行。
3. **总结填充**（“由此可见”“不言而喻”）——删掉后读者跟不上吗？跟不上该改的是论据。替读者按暂停键的解说导引（“这意味着”“背后的讯息是”）同算。
4. **成语堆砌**——同段 2 个以上且扎堆收尾；展开不出“具体发生了什么”就是拿它跳过思考。

### 句间

**通用**

1. **报幕过渡**（“从三个方面来看”“至少分三层”）——删掉后展开失去锚点吗？不失去就删；真实职责枚举是锚点，豁免。

**提示词**

1. **对称排比掩盖步骤缺失**——每项单独可执行吗？补不出“怎么算做到”的就是排比掩护的空项。
2. **首句复读标题**（“## 构建 本节介绍构建命令”）——删掉复述句，内容受损吗？

**散文**

1. **让步三拍**（“这些当然重要。”）——删掉让步句上下文通顺吗？通顺就删，全文上限 1 次。
2. **展示型三拍与 meta 点评**（“差一个字，天壤之别”）——删掉点评句受损吗？对比有力读者自己会感受到。
3. **“不是 X 而是 Y”密度**——否定半句纠正真实误解吗？两半各带信息吗？变体（“与其说”“重点不在”）同算。
4. **排比填充**（同句式连续 4 次+）——任意两项对调读感一样，就是机械的。
5. **句式死板**——连续 3 个同构或等长（±3 字）的分句，连环极短句同算；排比本身不是病。手法三选一：砍（留最强一项）、破（其中一项换句式）、拉（末项展开成具体场景）。
6. **反问句过渡**——知道答案就直接说，反问要靠铺垫赢得。

### 句内

**通用**

1. **缓冲词**（其实、往往、某种程度上、至关重要、必要的话）——删掉句意不变就是缓冲；每 500 字超 2 个超标。真条件分支（“仅在缓存开启时”）是限定，豁免。
2. **翻译腔**（“利用缓存榨取性能”“这个依赖很重”；散文变体：重量隐喻“变轻了”、抽象名词造词“彻底性”、物理动词配抽象宾语“拔到维度”）——换成朴素中文意思不变就是。中文已死的隐喻（“分量”）豁免。
3. **系动词回避**（“支持/提供/具备”轮换，“充当”“扮演着……角色”“作为……存在”）——换成“是/有”意思不变就直说。
4. **意义膨胀**（“标志着”“里程碑”“深远影响”，或自称“前所未有”）——说清具体事实后这句还剩什么？不确定是否新颖，就当不是。

**提示词**

1. **空原则无判定动作**——代理凭它分辨得了完成与未完成吗？给不出判据就补判据或删。
2. **黑话**：赋能、抓手、闭环、颗粒度、心智、底层逻辑、打法、沉淀，及非技术语境的链路、生态、范式——能换成说清具体做什么吗？换不出说明原句没信息。技术本义（调用链路、反馈闭环）豁免。
3. **模糊归因**（“业界普遍认为”）——有名有姓吗？删掉归因直接陈述还成立吗？
4. **伪精确**（“提升 30%”）——有基线或度量方式吗？遮住数字，约束力变吗？
5. **“进行＋动词”**——去掉“进行”直接说动词，意思不变就换。
6. **被字句与缺主语**——说得出谁执行吗？施事者已知就改主动；施事者真未知的陈述豁免。
7. **知识边界免责**（“以下内容可能不完全准确”）——这行字每次运行都成立吗？帮代理做了什么决策？生成时刻的死文本，删。
8. **预防性辩护**（“注意，这并不是说 X”）——找得到具体误读对象吗？找不到就删，真实限制写成例外条款。
9. **长定语链**——抽出主谓宾，指令还成立吗？一个分句“的”超 3 次多半在堆。

**散文**

1. **伪个人视角**——把“我”换成“有人”还成立，这个“我”就是伪装的。
2. **“我们”式共鸣**——换成“我”不敢说了，就是在借集体壮胆。

### 风格（通读收尾）

功能文本通篇语域单一是正常，此格不适用于提示词文档。

**散文**

1. **假口语分布均匀**——把口语词全删，语域反而更统一，就是按节奏撒的调料；真口语局部爆发。报备式停顿（“说真的”“老实说”当独立开场钩子）是它的位置变体。
2. **立场真空**——通读后说得出作者站哪边吗？“各有优劣、因人而异”是把判断滑开；给出具体选择条件的（“三人以下用 A，跨时区用 B”）放行。
3. **语域单调**——找得到语域切换吗（紧/松、文/白、长短交错）？通篇一档、得体但乏味即中。
4. **修辞无目的**——这个比喻让读者更懂或更有画面吗？段内比喻超一个且答不上就是装饰；“为了好看”的排比叠喻同删。
5. **词汇同质化**——抽掉带个人色彩的词（方言、俚语、只有这个作者会用的说法），文本变吗？不变即中。

## 改写红线

不改事实与观点，不编素材（缺细节问用户）；好句子原样留着并说明；目标是提高信息密度，铲平修辞得到的是说明书。

## 预防块

防 AI 味的正面约束，整体比判据更严；散文轨单列。可整段嵌入系统提示词或 AGENTS.md，也可写完后对照自检。

```markdown
## 写作约束

- 一个名词最多挂两个定语；到第三个就拆成短句，按条件顺序排开。
- 写完一句，删掉限定词（其实、往往、某种程度上、至关重要、必要的话）重读；意思不变就不留。
- 连续同构分句不超过 2 个；第三句换句式，或展开成比前两句长一倍的具体场景。
- 每段回答得出“推进了什么”（信息、情节、论点、情绪四选一）；答不上就删。
- 比喻先答三问：共享什么属性？是本体最需要说明的吗？喻体比本体好懂吗？答不出就直说。
- 例子过替换测试：换成另一对人、另一个系统还成立，就是套路。
- 结尾停在具体的判断或事实上；用成语和排比收束前先问，展开说是什么？
```

提示词文档追加：

```markdown
## 指令写作约束

- 每条指令过“完成与未完成可分辨”检查：代理读完知道何时算做到。给不出判据的原则删掉或补上判据。
- 黑话一律换成说清具体做什么；技术语境的本义用法保留。
- 数字承诺带基线或度量方式；没有基线就改定性描述加验收方式。
- 指令用主动句；施事者已知时不写被字句；指令句的隐含施事者不用补；说能力直接用“是/有”。
- 不写生成时刻的自我描述（“以下内容可能不完全准确”），每行字在每次运行时都要成立。
```

散文追加：

```markdown
## 散文写作约束

- 章节标题写“这节处理什么处境”，不把结论写进标题。
- “我们”不预设读者感受；“我”在一个段落只做一次锚点，后面让事实推进。
```
