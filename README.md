# workflow-skills

个人维护的工作流类代理技能集。每个技能一个目录，无脚本依赖。

| 技能 | 用途 |
|------|------|
| [grilling](grilling/SKILL.md) | 方案压力测试：持续盘问每个细节直到达成共识 |
| [writing-for-agents](writing-for-agents/SKILL.md) | 给代理写文档的规范：上下文指针、两种负载、信息层级、完成判据 |

## 安装

```bash
npx skills add brightmeows/workflow-skills
```

或直接复制技能目录到任意代理的技能目录。
